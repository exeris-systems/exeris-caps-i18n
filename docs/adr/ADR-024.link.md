# ADR-024 — Capability Composition Model (`@Provides` / `@Requires` / Build-Time Validation) (link stub)

**Authoritative copy:** [`exeris-docs/adr/ADR-024-capability-composition-model.md`](https://github.com/exeris-systems/exeris-docs/blob/main/adr/ADR-024-capability-composition-model.md)

ADR-024 is a **cross-repo** decision owned by `exeris-docs` (platform scope). It defines the four
capability annotations, the build-time resolution of the composition graph, and the five validation
predicates a build must satisfy before a cap set is composable.

## Why this stub exists

The capability module class is the whole of this repository's realization of ADR-024: one
`@CapabilityModule` and one `@Provides(service, version)` per service. There is no larger
implementation to read the decision out of; the declaration is short and the reasoning lives
upstream. Anyone changing that declaration is changing this repo's ADR-024 conformance.

## When to consult ADR-024 from this repo

- **Any edit to the module declaration.** The annotations are `@Retention(SOURCE)`, so they are erased
  at `javac` and the build-time pipeline is their only possible consumer. ADR-024 is the
  specification; the manifest is the evidence.
- **Adding a `@Requires`.** ADR-024 makes `initOrder` a topological sort of the `@Requires` DAG. A
  speculative edge is not inert: it changes the derived order for every SKU that includes this cap.
  A dependency on a service that may be absent at runtime is declared `optional = true`.
- **Changing `@Provides(version = ...)`.** The version is a semver contract on the service, not a
  label on the jar. While the capability is unreleased every contract is `0.1.0`.
- **Validation predicate 4 (host-runtime isolation).** Its build-time realization is the cap-tier
  Wall; see [`ADR-055.link.md`](ADR-055.link.md).
- **Obligations 8a / 8b** (lifecycle hooks, canonical content binding) are realized by
  `exeris-sdk-composition-lifecycle` and `exeris-sdk-composition-spec`. See
  [`ADR-053.link.md`](ADR-053.link.md) for the binding half.
